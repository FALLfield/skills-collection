# 毕业论文格式自查

按用户提供的学校规范（先改写成结构化规则）检查毕业论文 `.docx`，把可机读的格式问题写成 Word 批注，并给一页汇总。

**`rules/example_rules.json` 是虚构示例，不冒充任何真实学校的规范。** 真实使用时，请用自己学校的规范改写成同结构的文件。本工具不能直接「读懂」任意 PDF 规范原文。

本工具只检查规则里启用的可机读项，**不担保覆盖任何学校的全部条款**，不能代替学院审查。不提供、也不涉及「降重 / 过检测 / 绕过检测」。

本目录对应 `skills-collection` 仓库中的 `skills/thesis-format-check/`，可单独 sparse-checkout。本仓库只提供工具和测试记录，不含密钥或个人账号。

## 数据去向

检查在本机完成：不调用外部接口，不上传文档，不用 GPU。

## 怎么用

需要 Python 3 和 `python-docx` 1.2 或更高版本（用来写 Word 批注）：

```bash
pip install -r requirements.txt
python3 check_thesis.py \
  --rules rules/example_rules.json \
  --input 你的论文.docx \
  --output 论文_批注.docx \
  --summary 汇总.md
```

把学校规范改写成规则的字段说明见 `rules/README.md`。Agent 侧的步骤见 `SKILL.md`。

若输入不是完好的 `.docx`，或规则文件不是合法的 JSON 对象，脚本会在 stderr 打印一行中文说明并以退出码 2 结束，不会打印 Python traceback。规则文件为 `{}`（未启用任何检查项）时，会提示「规则为空，未启用任何检查项，未执行格式检查」，不会写成「未发现问题」。

## 在预先公开的 20 处样例错误上的结果（不是准确率）

测试前公开并冻结了一份虚构短篇毕业论文（不是真实学生论文）和 20 处已知错误清单（2026-11-12 16:52:56 Asia/Macau，UTC+8；哈希见 `tests/FROZEN.md`）。对照的是虚构示例规则。同一批不重跑凑数。

在这 20 处预先标注的错误上：

- **查出 20 处**：这 20 处都写出了对应的 Word 批注。
- **漏检 0 处**：没有「预先标注了但未写出对应批注」的条目。
- **误报 0 处**：样例里作为正确对照的段落（规范正文、正确的「第二章」和「2.1」、图 1 和图 2、参考文献 [1] 和 [3]、前置节罗马页码等）没有被标错。

这些数字只说明「在这份虚构样例、这一次跑次上的结果」，**不是准确率**，不能写成零差错，也不能外推到任意学校或任意稿件。逐条清单见 `tests/sample_errors.md`，对照脚本见 `tests/compare_to_gold.py`（按类别和位置配对，不依赖样例里的【E04】这类测试编号；去掉这些编号后再对照，分数仍然是查出 20、漏检 0、误报 0）。复现步骤见 `tests/REPRODUCE.md`。带批注的示例输出见 `tests/recorded_run/annotated.docx`。

## 已知局限

- 只检查规则文件里启用的可机读项：页边距，正文和标题的字体、字号、加粗，正文行距与首行缩进，标题编号连续性，图表题注格式与编号连续性，页眉文字，页码是否存在以及分节是否从指定页重启，是否为自动目录域，参考文献编号与是否含四位年份。
- 不检查规则里标为「待确认」的条目（例如封面模板是否强制、参考文献标点是否逐条符合 GB/T 7714）。
- 未覆盖扫描件、PDF、`.doc`，也未覆盖分章题注（如图 1-1）、英文论文版式、首页不同或奇偶页不同的页眉。
- 用户需要先把学校规范改写成 JSON；把规范 PDF 直接丢给脚本不能完成检查。
- 已有在线格式检测平台（有的学校指定使用，有的提供每日免费次数）。若学校已免费提供指定平台，通常不必再用本工具。本工具的差别是：对照你自己提供的规范、批注写回 Word、检查在本机完成。
- 需要能运行上面这条命令，或通过 agent 来运行。
