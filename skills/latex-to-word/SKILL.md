# LaTeX 论文转 Word

> 把已写好的 LaTeX 论文转成公式可在 Word 里编辑的 docx：交叉引用解析成编号，参考文献由 `.bib` 生成，并自动写出「成功 / 降级成图片 / 需手改」清单。

## 1. 触发条件

同时满足：

- 手上已有 LaTeX 论文源码（`.tex`，通常还有 `.bib` 和图片）；
- 要交给只收 Word 的期刊或学院行政；
- 要求公式仍可编辑（不是整页截图），交叉引用不能留成 `[sec:xxx]` 这种标签。

不要用它来「保证符合某期刊的全部格式」，也不要用它做文献真伪或降重。

## 2. 步骤

1. 安装 pandoc 3.x（须带 citeproc）、Python 3.9+ 与 `lxml`、poppler（`pdftocairo`）。不用 GPU，不登录。详见 `README.md`。
2. 在本目录运行（默认会给编号展示公式补题号，与 `visuals/` 右栏一致）：

   ```bash
   python3 latex_to_word.py 论文目录或主.tex -o 论文.docx --report 清单.md
   ```

   不要把 `.txt` 或其他非 tex 文件当输入：工具会拒绝，在 stderr 打一行中文并以非零退出。路径不存在或 tex 无法解析也一样。

3. 打开 `清单.md`，看「成功 / 降级成图片 / 需手改」。缺表、TeX 残片、未解析引用、源码 wraptable/wrapfigure 题注未进入 Word、以及「bib 中被引用的键数多于 docx 文献条数」（文献被静默丢弃）会自动列入「需手改」，不要只看「成功」。「静默丢弃」比对只比条数，查不出文献已进文献表、但正文或题注里的引用处却丢了的情况。
4. 在 Word 里抽查：公式能否进入公式编辑器、交叉引用编号、文末参考文献。

## 3. 不做什么

- 不担保排版符合某期刊，不替作者满足期刊全部格式要求。
- 自定义宏包、TikZ 等无法展开的内容只占位或降级，须在清单里写清，不假装已还原。
- 不检查「这句话是否真的来自这篇文献」，不做降重或过检测。
- 不登录账号、不搬运付费内容、不用 GPU、运行时不调用外部接口（全部本机）。

## 4. 验收（数字＋意义）

在公开许可明确的源码样例上，对**每一篇**把公式个数、交叉引用个数、参考文献条数与该篇官方 PDF 逐项计数；对不上就记失败。公式个数按官方 PDF 中真实编号展示公式来数。只写实测数字，不写准确率，不写「零差错」。本包在 5 篇 CC BY 4.0 样例上的结果见 `README.md`（第三轮 5 篇三项都对齐；前两轮历史数字也写在 README 里）。有未达标的项如实写原因，不改计数口径凑数。

## 5. 坑 / 已知失败

- 裸 pandoc 常把 `\ref` 留成 `[eq:ppd]`，数学里的 `\textcolor`、`\small`、`\textsc` 或自定义命令会导致公式变回 TeX 源码。本工具先展开宏、改写这些命令、解析编号，再交给 pandoc。
- 交叉引用是静态编号，不是 Word 自动更新域。无编号公式里的 `\label` 按 LaTeX 习惯挂到当前节（例如 `\autoref{eq:plonk}` 写成 Section II-C1）。
- 参考文献默认 IEEE 编号体例，与原文 `.bst` 可能不同；bib 键大小写不一致时会先对齐再交给 citeproc。缺 `year`/`date` 的条目会补 `n.d.`，并用 `\nocite` 保住表注里的引用，以免 citeproc 静默丢掉；清单会比较引用键数与文献条数，但「静默丢弃」比对只比条数，查不出文献已进文献表、正文或题注里的引用处却丢了的情况。源码 wraptable/wrapfigure 题注若未进入 Word，会另行列入需手改。
- 若用连续括号 `(1)…(K)` 在 PDF 全文计数，K 可能把正文枚举或文献卷号算进去，与真正的编号展示公式个数不同。本工具的 `oMathPara` 按源码编号展示公式来。详见 README。
- TikZ 不编译，清单记为需手改。`tabularx` 会改写成 `tabular`，仍可能有复杂表要手改。
- 生成的 docx 不写入本机绝对路径（CSL 只保留文件名）。同一输入在不同目录下转换，整文件 sha256 应相同。

## 6. 来源

验收标准在测试前写定：对每篇公开源码样例，公式、交叉引用、参考文献条数与该篇官方 PDF 逐项计数。第一轮、重做后与第三轮测试均在 2026-11-12（Asia/Shanghai，UTC+8），结果见 README。
