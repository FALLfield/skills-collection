# 预埋 20 处错误清单（测试前公开固定）

> 本文档与 `gold_errors.json`、`sample_thesis.docx` 在检查跑次之前固定。
> 样例内容全部虚构，不来自真实学生论文；对照的是虚构示例规则，不冒充真实学校规范。

## 样本构成

- 一份短篇虚构毕业论文 docx：封面、中英文摘要、手工目录、第1章（含图）、第二章（含表）、第4章（跳号）、参考文献。
- 正确对照：若干规范正文段落、正确的「第二章」「2.1」、图 1 和图 2、参考文献 [1] 和 [3]、前置节罗马页码。
- 故意埋入下面 20 处已知错误。段落中的【E04】等标记只用于对照本清单，不是论文内容。

## 20 处埋错

| 编号 | 类别 | 说明 |
| --- | --- | --- |
| E01 | `margin` | 正文节（第 2 节）左边距为 2.54 cm，规范要求 3.17 cm。 |
| E02 | `margin` | 正文节（第 2 节）上边距为 2.00 cm，规范要求 2.54 cm。 |
| E03 | `margin` | 前置节（第 1 节）右边距为 2.00 cm，规范要求 3.17 cm。 |
| E04 | `font_cn` | 一段正文中文字体为楷体，规范要求宋体。 |
| E05 | `font_size` | 一段正文字号为 14 磅，规范要求 12 磅。 |
| E06 | `heading_font` | 「第1章 绪论」中文字体为宋体，规范要求黑体。 |
| E07 | `heading_size` | 「第1章 绪论」字号为 14 磅，规范要求 16 磅。 |
| E08 | `heading_bold` | 二级标题「1.1 研究背景」未加粗，规范要求加粗。 |
| E09 | `line_spacing` | 一段正文为单倍行距，规范要求 1.5 倍。 |
| E10 | `indent` | 一段正文无首行缩进，规范要求 2 字符。 |
| E11 | `heading_number_seq` | 章号从「第二章 方法」跳到「第4章 结论」，缺第三章。 |
| E12 | `heading_number_seq` | 二级标题从「1.1 研究背景」跳到「1.3 研究意义」，缺 1.2。 |
| E13 | `caption_seq` | 图题号从 图2 跳到 图4，缺 图3。 |
| E14 | `caption_format` | 表题写成「表一」，规范要求阿拉伯数字「表1」。 |
| E15 | `caption_size` | 「图 5」题注字号为 12 磅，规范要求 10.5 磅。 |
| E16 | `page_number_missing` | 正文节页眉页脚没有 PAGE 域。 |
| E17 | `page_number_restart` | 正文节页码未从 1 重新起编。 |
| E18 | `header` | 正文节页眉不是规定文字「示例大学本科毕业论文」。 |
| E19 | `toc` | 目录是手工文字，不是 Word 自动目录域。 |
| E20 | `reference_year` | 参考文献 [2] 缺少四位年份。 |
