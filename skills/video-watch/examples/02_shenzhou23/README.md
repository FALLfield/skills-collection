# 案例 2：竖屏新闻短片的分镜与画面字

**解决了什么：** 把一支 32 秒的竖屏新闻短片拆成带时间码的 6 镜联系图。口播转写错字较多，但 OCR 仍读出了「乘组航天员张志远」「籍贯甘肃白银」「乘组航天员黎家盈」等画面字；同时也漏掉了第 1 镜的大标题，水印常只认出「视频」。

在这支 32 秒样例上的结果：6 个镜头，生成联系图。原视频不随仓库分发。
