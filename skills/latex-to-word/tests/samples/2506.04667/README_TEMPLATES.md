# 本目录不附带 neurips_2025.sty

随 arXiv 源码出现的 `neurips_2025.sty` 没有 license / copyright 行，因此不随本包分发。

请从官方来源自行下载后放到本目录（与 `main.tex` 同级），再做完整 LaTeX 排版：

- NeurIPS 2025 样式包：https://media.neurips.cc/Conferences/NeurIPS2025/Styles.zip
- 会议说明：https://neurips.cc/Conferences/2025/PaperInformation/NeurIPS-FAQ

复现本工具已保存的 Word 转换结果（`tests/outputs/2506.04667/`）不需要这份文件。说明见 `../LICENSE_AND_ATTRIBUTION.md` 与 `../../README.md`。
