英文参考文献核查

把参考文献列表粘贴到下面，点「开始核查」。工具会对照 Crossref、OpenAlex、Europe PMC，标出已验证、信息部分不符、查无此文、疑似编造或核查失败。查不到时不会编造一条看起来正确的文献来替代。只给 DOI 或 DOI 链接且能解析时，会标「已验证」并展示库中记录。本工具面向以英文文献为主的理工或医学学生；以中文文献为主的人不是目标客户。

请保持联网。浏览器会把题名、DOI 或 PMID 发送到上述公开学术数据库查询，不上传全文。
不支持知网、万方。中文期刊常常只能标「查无此文」，不能确认它是假的（例如公开报道过的不存在中文期刊，在这里也只能标查无此文）。网络或接口失败（超时、连不上或 HTTP 429）会标「核查失败/无法下结论」，不会写成「查无此文」。这不是能拦住一切编造文献的工具。
对照来源：api.crossref.org、api.openalex.org、www.ebi.ac.uk/europepmc（均免费、无需密钥）。查询时会把题名或 DOI 发给这些公开库，不上传全文。不支持知网、万方。浏览器不允许网页修改 User-Agent，因此 Crossref 的礼貌标识无法按脚本那样放进请求头；OpenAlex 请求会附带 mailto 参数（可在上方填写，默认 refcheck@localhost）。
