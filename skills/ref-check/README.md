# 参考文献核查（对照公开数据库）

把参考文献列表交给工具，对照 [Crossref](https://www.crossref.org/)、[OpenAlex](https://openalex.org/)、[Europe PMC](https://europepmc.org/) 做存在性和字段核对，给出带原文链接的报告。

**适合谁：** 以引用英文期刊或会议论文为主的理工、医学学生。  
**以中文文献为主的人不是目标用户。** 本工具不支持知网、万方。中文条目常常只能标「查无此文」，**不能据此确认它是假的**。

这不是能拦住一切 AI 编造文献的工具，也不检查「正文里那句话是否真的来自这篇文献」。查不到时，**不会编造**一条看起来正确的参考文献来替代。

本仓库只提供工具和测试记录，不含付费内容，也不包含密钥或个人账号。

## 怎么用

### 网页（不用安装）

用浏览器打开 `ref-check.html`，把参考文献粘贴进输入框，点「开始核查」。需要联网。查完可打印或另存为 PDF。可在页面上选填联系邮箱，供 OpenAlex 的 `mailto` 参数使用（默认 `refcheck@localhost`）。

### 命令行（Python 3，仅标准库）

```bash
python3 check_refs.py references.txt --mailto you@school.edu -o report.html
```

还可使用 `--md`、`--json` 写出 Markdown 或 JSON。脚本只用 Python 标准库。

## 怎么看结果

- **已验证**：公开库能对上，关键字段一致。请点开报告里的原文链接再确认一眼。
- **信息部分不符**：大概是同一篇，但年份、作者、页码、期刊或 DOI/PMID 对不上。
- **查无此文**：这几个库正常返回了，但找不到足够像的记录。**不等于一定是假的。**
- **疑似编造**：英文条目写得很完整却完全找不到；或 DOI/PMID 指向另一篇完全不同的文章；或短通用题名撞上同刊另一篇真实文献（报告会附上该记录的原文链接，请人工核对）。**不能单凭这一条就下学术不端的结论。**
- **核查失败/无法下结论**：网络或接口出错（超时、连不上、HTTP 429）。**不要把它理解成「查无此文」。** 稍后重试。

示例输入见 [`examples/`](examples/)。

## 已知局限

- 只查 Crossref、OpenAlex、Europe PMC，不支持知网、万方；中文期刊、学位论文、书籍经常只能标「查无此文」。
- 网络或接口限流时会标「核查失败」，不能改记成「查无此文」。
- 短通用题名可能撞上同刊另一篇真实文献。当前策略是标「疑似编造」或请核对原文，并附上找到的记录链接，而不是放行成「已验证」。
- 库内偶发脏作者字段、少见会议摘要页码、部分 BibTeX / IEEE / 中文混排格式仍可能把同一篇标成「信息部分不符」。
- 不检查引文是否真的支持正文中的那句话。
- 网页与脚本核心规则相同，但上面的 100 条计次以脚本联网实测为准。
