# 案例 1：口播转写为空时，仍能从画面读出发射信息

**解决了什么：** 这支 121 秒的纪录短片几乎没有可用口播（配乐盖过人声，转写为空），但分镜联系图和 OCR 仍读出了发射时刻、文昌航天发射场、舱体尺寸、「发射任务取得圆满成功」等写在画面上的信息。

在这支 121 秒样例上的结果：切出 24 个镜头，生成带署名的联系图；口播转写为空；OCR 能读出硬字幕，台标水印常被误读。原视频不随仓库分发。
