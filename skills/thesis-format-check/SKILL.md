# 毕业论文格式自查（按学校规范给 docx 写批注）

## 1. 触发条件

用户交来毕业论文 docx，并提供学校格式规范（或已转好的结构化规则），要求按规范自查、把问题写成 Word 批注。只用于格式检查。

## 2. 步骤

1. 向用户要两样东西：论文 docx，以及学校规范（PDF、Word 或要点均可）。不要用不经授权的学生原文做演示。
2. 把规范改写成结构化规则（对照 `rules/example_rules.json` 的字段）。**示例规则是虚构的，不得冒充真实学校。** 规范里有口径之争的条目标进 `pending`，不写入自动检查、不下结论。本工具不能直接解析任意规范 PDF。
3. 在本机运行（数据不出本机，不调用外部接口，不用 GPU）：
   `python3 check_thesis.py --rules <规则.json> --input <论文.docx> --output <批注.docx> --summary <汇总.md>`
4. 若脚本以退出码 2 结束，把 stderr 里的一行中文说明告诉用户（不是完好的 docx，或规则不是合法的 JSON 对象），不要把 traceback 丢给用户。
5. 把带批注的 docx 和一页汇总交给用户，并写明只检查了规则里启用的可机读项，不能代替学院审查。规则为 `{}` 时，汇总会写「规则为空，未启用任何检查项」，不要说成「没发现问题」。

## 3. 不做什么

- 不担保「通用到任何学校的全部条款」。只检查规则文件启用的可机读项：页边距；正文和标题的中西文字体、字号、加粗；正文行距与首行缩进；标题编号连续性；图表题注格式与编号连续性；页眉文字；页码是否存在、分节是否从指定页重启；是否为自动目录域；参考文献编号与是否含四位年份。
- 不碰「降重 / 过检测 / 绕过检测」，不改论文正文（只写批注。若原文没有任何段落，会添加一段说明文字以便挂载批注）。
- 不登录账号、不上传文档、不调用外部接口、不用 GPU。
- 不把虚构示例规则当成某所真实学校的规范。
- 不把测试计数写成准确率或「零差错」。

## 4. 验收（数字＋意义）

在测试前已公开的 20 处埋错样例上跑一次（`tests/sample_thesis.docx` 与 `tests/gold_errors.json`，2026-11-12 16:52:56 Asia/Macau 冻结，同一批不重跑凑数）：

- **查出 20 处**：预先标注的 20 处错误都写出了对应批注。只说明「在这份虚构样例、这一次跑次上对上了这 20 处」，不是准确率，不能外推。
- **漏检 0 处**：没有预先标注但未写出对应批注的条目。
- **误报 0 处**：正确对照段（规范正文、正确的第二章和 2.1、图 1 和图 2、参考文献 [1] 和 [3] 等）没有被标错。

对照脚本按类别和位置配对，不依赖【E04】这类测试编号。复现见 `tests/REPRODUCE.md`。这些数字不能写成「零差错」。

## 5. 坑 / 已知失败

- 中文字体要读 OOXML 的 `eastAsia`，只看 python-docx 的 `font.name` 会漏掉。
- 字号和加粗可能写在样式上而不是 run 上，必须沿样式链取有效值，否则会误报「未设置」。
- 页边距要带公差（示例规则 0.05 cm），否则 3.17 cm 与 1.25 英寸会对不上。
- 手工目录行看起来像「第1章 …… 1」，必须和真正的章标题分开，否则会把目录当成正文标题并误报跳号。
- 「表一」这类先判格式再判连续性，避免一条错报两次。
- 非 docx、损坏的 docx、规则不是合法 JSON 或不是对象：一行中文写到 stderr，退出码 2，不打印 traceback（与找不到文件相同）。
- 规则文件为 `{}` 时提示「规则为空，未启用任何检查项，未执行格式检查」，不写成「未发现问题」。
- LibreOffice 把 docx 转成 PDF 时不画 Word 批注气泡；`visuals/before_after.png` 的红色气泡是脚本按锚点补画的。交给用户的 docx 里仍是真正的 Word 批注。
